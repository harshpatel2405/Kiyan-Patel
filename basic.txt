operator
--------
Operator , operand

operand operator operand 

1. Arithmetic Operator 
    +   -    *    /    %   // (floor division) (will return you value without point (less than number))
    ** (exponent (base,power))

2. relational operators 
    <    >    <=   >=   ==  !=

    5 < 5  -> false
    5 > 5  -> false 
    5 <= 5 -> true
    5 >= 5 -> true 
    5 == 5 -> true (checking (if both lhs and rhs are same)) (comparison operator)
    5 != 5 -> false  (not equal to)

3. Logical Operator 
    and  -> both conditions are true 
    or   -> any one of the condition should be true
    not  -> alters the output 

4. membership operator 
    is y IN kiyan ('IN' is dalal)
    is y NOT IN Kiyan
